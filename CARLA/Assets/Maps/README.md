# ASURT map inputs and track data

The Windows and Ubuntu installers copy this collection into **ASURT Workspace → Assets → Maps**. The default path in Ubuntu or WSL is `~/.local/share/asurt/workspace/Assets/Maps`.

- [CSV](CSV/) contains shared example layouts. [JSON](JSON/) contains training layouts and historical noisy-input tests.
- [Competition2027](Competition2027/) contains the current Acceleration and Skidpad cone layouts in CSV and JSON, plus the reference paths. Choose **2027 Acceleration** or **2027 Skidpad** in Track Importer to use the current presets.
- [SilverstoneSection](SilverstoneSection/) contains the OpenDRIVE road and spawn settings. Install or switch to the cooked Silverstone Split level through **Map Packs**. The base simulator includes FlatAsphalt.

The [current Competition 2027 ZIP](Competition2027/FSUK_2027_Dynamic_Orange_Handbook_20261122.zip) is a downloadable copy of the event layouts. The [earlier course ZIP](Competition2027/FSUK_2027_Acceleration_Skidpad_Cone_Tracks.zip) and [orange-gate ZIP](Competition2027/FSUK_2027_Acceleration_Skidpad_Orange_Gates_20261122.zip) preserve older variants for reproducing tests.
